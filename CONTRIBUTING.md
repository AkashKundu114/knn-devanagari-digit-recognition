# Contributing

Suggestions and bug reports are welcome.

1. Open an issue describing the problem or proposed improvement.
2. Keep changes focused and document any change to preprocessing, data loading or evaluation.
3. Do not commit raw dataset images, Kaggle credentials, API tokens, virtual environments or generated machine-specific outputs.
4. Run the project on a valid local dataset before claiming a change improves model performance.
5. Never report fabricated metrics. Include the command, configuration and relevant output when reporting evaluation results.

By submitting a contribution, you agree that your contribution may be distributed under the repository's MIT License.
